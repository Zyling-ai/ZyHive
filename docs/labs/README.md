# ZyHive Labs

Labs 收录已有实验实现、但尚未进入稳定产品承诺的能力。当前 Labs 不等于预览版 Stable，也不表示有确定转正日期。

## 共同边界

- 默认关闭或不位于默认用户路径；启用前必须确认当前版本开关、依赖和数据目录。
- API、数据格式、页面、默认值和迁移方式可能发生破坏性变化。
- 只在隔离、可回滚、非关键环境验证；先备份并记录启用前版本和配置。
- 不用于资金托管、工资结算、收益确认、合规评分、安全授权、生产 SLA 或其他高风险自动决策。
- 页面或路由存在不表示对应子系统已启用；运行时 404、501、503 可能是实验开关关闭、能力未完成或依赖未初始化。
- 发现安全、数据完整性或不可逆副作用风险时，应立即停用并回滚，不以“实验”标签豁免安全要求。

- SkillOpt：当前边界见 `docs/user-guide/skills-and-skillopt.md`；`docs/archive/designs/skillopt-design.md` 是设计参考，不是稳定承诺。

## 从 Labs 转为 Stable

转正必须经过明确评审，至少满足：

1. 默认产品路径、兼容与迁移策略已确定；
2. 核心行为、失败路径和数据恢复有自动化测试；
3. 安全、隐私、权限和运维边界完成审查；
4. 用户、管理员和开发者文档完整；
5. 正式 Release 门禁验证通过；
6. `docs/reference/feature-status.md` 与[覆盖矩阵](../governance/coverage-matrix.md)同步更新。

仅移除环境变量开关、增加页面、完成演示或合并代码，均不足以自动转为 Stable。
