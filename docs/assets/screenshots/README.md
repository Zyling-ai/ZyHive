# 界面截图说明

本目录截图来自隔离运行的正式 `26.8.2v1` macOS arm64 资产，统一使用 826×1024 视口。实例只包含虚构成员和空白业务数据，不含真实 API Key、管理员 Token、联系人、会话内容或基础设施地址。

截图用于帮助定位界面，不是功能状态证据。页面行为、字段和支持边界以当前代码、测试、[功能状态](../../reference/feature-status.md)及对应正文为准。

更新截图时：

1. 使用隔离临时 HOME、随机 Token 和测试端口；
2. 不接入真实模型、渠道、联系人或客户数据；
3. 截图前检查输入框、URL、日志和通知；
4. 保持同一视口并使用语义化文件名；
5. 运行 `make docs` 检查尺寸与引用。
